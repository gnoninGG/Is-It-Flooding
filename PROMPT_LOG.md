# Agentic workflow log

This log documents the AI-assisted setup of Is It Flooding? for the Superteam Agentic Engineering Grant.

## 2026-08-28

1. Defined the project as a community flood-intelligence web app for the Philippines.
2. Chose a Next.js + TypeScript public map paired with an Anchor program because the project needs both a user-facing web app and a custom, verifiable report-attestation primitive.
3. Scoped on-chain data to coarse, non-sensitive report attestations; detailed evidence and precise location remain off-chain.
4. Planned Solana participation rewards and compressed-NFT badges without presenting them as an investment product.
5. Selected a polished neutral emergency-map interface with high contrast, responsive layout, visible keyboard focus, and explicit loading, empty, and error states.
6. Generated the initial README, frontend layout, Anchor program, project guidance, and development configuration.
